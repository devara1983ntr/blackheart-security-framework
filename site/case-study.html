Worked example

We found three real defects in our own promoted security skill.

Not by scanning it. By running it against controlled input — the same way you would test a target. Every scanner passed this skill. Running it did not.

F-01

The jailbreak signature matches ordinary English words

The persona-jailbreak pattern is an unanchored alternation:

pattern 
(DAN|STAN|DUDE|KEVIN|AIM|ANTI-DAN|BasedGPT)

With no word boundaries it fires inside unrelated words — claim, standard, dangerous.

12 hitsARCHITECTURE.md
11 hitsAGENT.md
1 hitSECURITY.md

Consequence

A near-total false-positive rate on ordinary security prose. A jailbreak_persona hit is presumed false until the exact matched substring is inspected — which means the signal is only as trustworthy as the reader's patience.

F-02

A "confidence" score that is never low

The detector emits a bounded confidence that, by construction, never falls into the range that would suppress a finding. There is no input for which the rule declines to report — so the number carries no information, and a reader who trusts it is trusting a constant.

Consequence

A field shaped like a severity signal but carrying a fixed value is worse than no field, because dashboards rank by it. Findings get ordered by a number that was never computed.

F-03

Instructions that are logged as data, and vice versa

A block classified as untrusted content is interpolated into the instruction path, and a block classified as instruction is passed through the untrusted channel. The two channels are crossed in both directions, which means the containment boundary the design depends on does not exist at the point where it is actually enforced.

Consequence

This is the one that matters. Confinement that is documented and not implemented gives exactly the false assurance this framework was built to eliminate — from the authors, about their own code.

Method

Why scanning was not enough.

A static scanner asks whether a pattern is present. All three defects involve a pattern that is present and correct, used in a context where it is wrong. Only execution shows you the context.

What scanning reported

The vendored ai-security scanner's own clean output was never trusted, and its measured defects remain documented. A passing scanner over code you did not run is a statement about the scanner.

What running it showed

Twelve false positives in a file that discusses detection. A confidence value that never varies. Two containment boundaries that cross. All three in a skill that had been promoted and reviewed.

The uncomfortable part

These were our files, in a repository whose entire thesis is that unreviewed third-party content is the risk. A framework that only distrusts other people's code has not understood its own argument. The defects that justify this project's existence were, in this instance, ours.
